# React Analyticts Dashboard 

A modern and responsive analytics dashboard built with React, Vite and Rechaarts. The dashboard provides data visualization, activity tracking, dark mode support, and Interactive UI components.

## Live Demo:

  [http](https://jamila-ait-hamou.github.io/Dashboard-Page/)

## Features

  - Interactive Line Chart
  - Interactive Bar Chart
  - Weakly, Monthly, and Yearly data filters
  - Recent Activity Table
  - Activity Search & Filtering
  - Activitiy Search & Filtering
  - Status Badges (Completed, Pending, Failed)
  - Dark Mode
  - Responsive Design
  - Fixed Header
  - Collapsible Sidebar
  - Animated Stat Cards


## Technologies Used

  - React
  - Vite
  - JavaScript(ES6+)
  - CSS3
  - Reacharts
  - React Icones
  - Git & GitHub
